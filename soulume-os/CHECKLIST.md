# SOULUME OS — Conveyor Checklist

## Start
- [ ] START — Anton actually begins the SOULUME workday; no fixed wake-up time.
- [ ] BRIEF — ChatGPT states the full output cluster (Long + Shorts + Community + Threads + Instagram) and asks only the five Architect questions.

## Core episode
- [ ] SPEC — machine-readable episode spec exists.
- [ ] ASSETS — all required audio + visuals exist; no paid purchase required.
- [ ] AUDIO_CORE — unique multi-track core assembled; no single-track infinite loop.
- [ ] VISUAL_CORE — approved S. continuity; subtle motion/anomaly; no identity drift.
- [ ] RENDER — long-form MP4 generated.
- [ ] QA — PASS: streams, duration, size, decode start/middle/end, sampled silence.
- [ ] PACKAGE — title, description, RU translation, thumbnail, tags, S. note, playlist metadata.

## Mandatory distribution cluster
- [ ] YOUTUBE_LONG — final long-form package.
- [ ] SHORTS — default 4–6 distinct 9:16 traffic-acquisition cuts from approved Episode assets.
- [ ] SHORTS_LINK — each Short has explicit long-form Episode destination/related-video intent where supported.
- [ ] YT_COMMUNITY — at least one native Community package; publish if connector supports it, otherwise mark exact blocker.
- [ ] THREADS — native Threads copy/package, not copied mechanically from YouTube.
- [ ] INSTAGRAM_REELS — Reel package from approved vertical assets once connection exists.
- [ ] INSTAGRAM_STORIES — optional Story/still sequence when it improves the episode launch.
- [ ] TRANSLATIONS — all English copy that Anton will publish also has Russian translation for review/context.

## Publication
- [ ] PUBLISH — only verified platforms/connections; do not block YouTube because one secondary social network is disconnected.
- [ ] VERIFY — inspect actual public URLs; never treat “scheduled” as “published”.
- [ ] ANALYTICS — 24h / 72h / 7d metrics captured across available surfaces.
- [ ] MEMORY — one bottleneck + one experiment + canon update saved.

## Zero-spend decision ladder
1. Existing assets/access.
2. Free quota.
3. Local/cloud FFmpeg/Python/open-source fallback.
4. Simplify scene/motion without breaking story.
5. Prepare-but-block distribution package if a connector is unavailable.
6. Never purchase automatically.

## Automatic rejection
- audio missing, noise-only or unexpected silence;
- wrong episode/version/language;
- file exceeds publisher limit;
- visible S. identity drift / malformed body/hands;
- public use of full heroine name instead of S.;
- lore contradiction;
- thumbnail/title mismatch;
- Short is a near-duplicate with no distinct hook;
- social copy mechanically duplicates another platform without adapting to native format;
- upload destination not verified SOULUME.
