# SOULUME OS — Production Checklist

## A. Architect Brief
- [ ] Destination/location received
- [ ] 3–5 observations/experiences received
- [ ] S. realization received
- [ ] Music vector/listening job received or inferred
- [ ] Optional lore/visual seed received or inferred
- [ ] No unnecessary technical questions asked

## B. Episode Spec
- [ ] Episode number locked
- [ ] Duration locked
- [ ] Listener utility/search job defined
- [ ] Music palette defined
- [ ] Audio structure defined
- [ ] 6–10 visual scenes defined
- [ ] One backward canon connection
- [ ] One unresolved forward seed
- [ ] One subtle anomaly/world-response moment
- [ ] S. remains consistent with Visual Bible
- [ ] No full-name "Soul" signature; public signature is S.

## C. Assets
- [ ] Music sources exist and are licensed/usable
- [ ] No paid generation used under ZERO EXTRA SPEND
- [ ] Keyframes/visuals exist
- [ ] Thumbnail candidate exists
- [ ] File names follow SOULUME_EPXX_* convention

## D. Render
- [ ] Full multi-track audio core built
- [ ] Crossfades present
- [ ] Whole audio core loops, not one track
- [ ] Full visual core built
- [ ] Visual core loops as a sequence
- [ ] 1920×1080 default
- [ ] H.264 + AAC
- [ ] Output size stays under current publishing-route ceiling

## E. Automatic QA — hard gate
- [ ] Video stream exists
- [ ] Audio stream exists
- [ ] Duration matches target ±2s
- [ ] File decodes at start
- [ ] File decodes at middle
- [ ] File decodes near end
- [ ] No sampled accidental silence
- [ ] No known noise-only failure
- [ ] File-size ceiling passes
- [ ] Episode number/file name correct
- [ ] If any hard gate fails: DO NOT PUBLISH

## F. Human-quality QC where available
- [ ] First 3–5 min sound coherent
- [ ] Random middle excerpt coherent
- [ ] Final excerpt coherent
- [ ] No attention-grabbing transition that breaks listening job
- [ ] Visual motion does not compete with music

## G. Package
- [ ] Search-informed English title
- [ ] Russian title translation for Anton
- [ ] English description
- [ ] Russian description translation
- [ ] Thumbnail
- [ ] S. Little Note / first comment
- [ ] Tags / queries
- [ ] Category MUSIC
- [ ] madeForKids=false
- [ ] correct AI disclosure
- [ ] Playlist / previous-next episode logic
- [ ] Shorts hooks prepared

## H. Publish / Verify
- [ ] Correct SOULUME brand/channel
- [ ] Media handoff completed
- [ ] Upload/schedule accepted
- [ ] Final YouTube URL verified
- [ ] Correct title/thumbnail/description visible
- [ ] Audio spot-check on published version
- [ ] Only then status = PUBLISHED

## I. Feedback loop
- [ ] 24h metrics recorded
- [ ] 72h metrics recorded
- [ ] 7d metrics recorded
- [ ] Top audience comments/theories classified
- [ ] One primary bottleneck selected
- [ ] One next experiment selected
- [ ] World Bible / Episode Memory updated
