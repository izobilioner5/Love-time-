# Love Time ❤️

Минимальный MVP приложения: одно ежедневное напоминание проявить любовь.

## Запуск

```bash
npm install
npx expo start
```

На iPhone открой проект через Expo Go или development build.

## MVP

- один экран
- переключатель Love Time
- запрос разрешения на уведомления
- ежедневное локальное уведомление в 12:00
- отключение уведомления тем же переключателем

Текст уведомления:

> Сейчас время проявить любовь. Кому ты можешь её дать?
