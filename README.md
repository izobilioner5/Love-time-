# IZOBILION Need / Give MVP

Тест главной гипотезы IZOBILION: люди указывают, что им сейчас нужно и что они могут дать, а сеть помогает находить полезные совпадения.

## Telegram-сценарий

1. `/start`
2. Пользователь пишет до 3 запросов: **что нужно**.
3. Пользователь пишет до 3 ресурсов: **что может дать**.
4. Указывает город или `онлайн`.
5. Профиль сохраняется в Cloudflare KV.
6. Бот ищет релевантные Need/Give-совпадения среди участников.
7. `/match` — повторный поиск совпадений.
8. `/profile` — показать свой профиль.
9. `/reset` — удалить профиль и начать заново.

## Что проверяем за первую неделю

- 30–50 участников;
- 100+ реальных Need/Give записей;
- 15+ состоявшихся знакомств;
- 5+ запросов, которые реально закрылись через сеть.

## Инфраструктура

Worker: `telegram-worker.js`

Нужны Cloudflare Worker secrets:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_WEBHOOK_SECRET`

И KV binding `SUBSCRIBERS` в `wrangler.jsonc`.

## Важно

Это intentionally ручной/простой MVP. Matching пока лексический, без LLM и embeddings. Если сеть покажет реальные полезные совпадения, следующий шаг — семантический AI matching, цепочки ресурсов и метрики закрытых запросов.
